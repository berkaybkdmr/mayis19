# 1. yil websitesi

Hazir onizleme:

```text
http://127.0.0.1:5173/
```

En hizli kullanim:

1. Siteyi ac.
2. `Evet` dugmesine bas.
3. Fotograflar otomatik akar.
4. `Ani Oyunu` dugmesiyle eslestirme oyununu ac.
5. `Foto Puzzle` dugmesiyle 3x3 fotograf puzzle oyununu ac.

Kalici fotograf listesi icin:

- Fotograflar `assets/photos` klasorunde durabilir.
- Su an site `photo-1.jpg` ile `photo-90.jpg` arasindaki fotograflari kullaniyor.
- Daha fazla fotograf eklersen `script.js` icindeki `configuredPhotos` sayisini guncelle.

Metni degistirmek istersen acilis yazisi `index.html` icindeki `love-note`
paragrafidir.
